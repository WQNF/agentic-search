# 人工评分指引（指标 17–20）

## 抽样

- 从 30 份 E2E 报告中抽 10 份；
- 分层：US 4 / CN 3 / HK 3；
- 至少 2 份 partial_success / 降级报告；
- 固定随机种子（记录抽样脚本或 seed）；
- 隐藏系统/基线身份，两位评分者独立打分。

## 评分表

文件：`human_scores.csv`

| 列 | 含义 |
|---|---|
| `report_id` | 运行 ID（`runs/<run_id>`） |
| `rater` | 评分者代号（R1/R2） |
| `completeness` | 完整性 1–5 |
| `factuality` | 事实一致性 1–5 |
| `structure` | 结构 1–5 |
| `actionability` | 可 action 性 1–5 |
| `notes` | 扣分理由/证据行号 |

## 评分锚点

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 完整性 | 缺 2+ 个核心 section，或关键财务/新闻大面积缺失 | 5 个 section 都有，但财务/新闻其一明显单薄 | 5 个 section 充实；指标、新闻、风险、结论齐全 |
| 事实一致性 | 多处数值与官方/输入矛盾，或明显编造 | 大部分可核对，个别口径/期间不一致 | 抽查 5 个数值全部一致；无编造；期间/币种标注清楚 |
| 结构 | 标题层级混乱、表格错位、难读 | 7 章齐全、有表格，但逻辑/排版一般 | 层级清晰、表格规范、论证连贯、附录完整 |
| 可 action 性 | 只有泛泛而谈，没有结论/风险/催化 | 有结论和风险，但缺条件/仓位/投资者适配 | 结论明确、给出适用投资者/关键变量/风险触发条件 |

## 流程

1. 两人各自读报告、独立打分，不交流；
2. 记录每项扣分的证据（章节/行号/数值）；
3. 汇总时先算原始平均，再讨论分歧 >1 分的项；
4. **保留原始分**，不要只留讨论后的分；
5. 报告：均值、SD、两人差值 ≤1 的比例；样本 ≥10 可补 ICC(2,1)。

## 注意

- 不要因为“格式好看”给事实一致性高分；
- 不要因为“结论大胆”给可 action 性高分，要看是否有依据/条件；
- 数值核对以 `ground_truth.csv` 的同期值为准；期间/币种不一致要扣分并在 notes 写明。
